Kenapa Sprite Perlu Mengirim Pesan? 💬

broadcast: jump

Bayangkan Chicky ingin meminta Worm untuk melompat. Chicky tidak menggerakkan Worm secara langsung, tetapi mengirim pesan.

Di Scratch, cara mengirim pesan seperti ini disebut broadcast.

Broadcast dan When I Receive 🧩

broadcast digunakan untuk mengirim pesan. Pesan itu baru bekerja jika sprite lain punya block when I receive untuk menerima pesan tersebut.

Ask dan Answer: Bertanya ke User ⌨️

Block ask dipakai untuk bertanya kepada user. Setelah user mengetik jawaban, Scratch menyimpannya di block answer.

Untuk hari ini, anggap answer seperti tempat penyimpanan sementara. Nanti jawaban itu akan kita cek dengan conditional.

Kenapa Jawaban Harus Disimpan? 🧠

1. Program bertanya: Enter your command.
2. User mengetik: turn on the lamp.
3. Jawaban masuk ke block: answer.
4. Program mengecek: answer = command tertentu?
Kalau jawaban tidak disimpan, program tidak punya data untuk dicek. Karena itu, answer berperan seperti variabel sederhana.

Mengecek Jawaban dengan Operator Pembanding 🟩

if answer = turn on the lamp then
broadcast turn-lamp-on

Operator pembanding mengecek apakah isi answer sama dengan command yang kita tentukan.
