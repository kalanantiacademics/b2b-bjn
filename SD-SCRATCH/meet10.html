CORE CONCEPT

Looping Menyederhanakan Algoritma

Programming mengajarkan kita menyusun instruksi sesederhana mungkin. Kalau ada code yang sama ditulis berkali-kali, kita bisa mulai berpikir: bisa dibuat loop nggak ya?

Loop tidak membuat program berbeda. Loop membuat instruksi yang berulang jadi lebih pendek, rapi, dan mudah dibaca.

PROGRAMMING PRINCIPLE

DRY: Don't Repeat Your Code

DRY adalah aturan penting di programming. Kalau kamu merasa terlalu banyak menulis code yang sama berkali-kali, berarti sudah waktunya memikirkan loop.

Pertanyaan cepat: “Apakah block ini diulang dengan pola yang sama?” Jika iya, coba pakai repeat, forever, atau repeat until.
REAL LIFE LOOP

Kegiatan Sehari-hari Juga Banyak yang Berulang

Looping tidak hanya ada di Scratch. Banyak aktivitas harian juga punya pola yang diulang.

Bersihkan Kaca

Ulangi gerakan sampai kaca bersih.

Pasang Kancing

Ulangi sampai semua kancing terpasang.

Siram Tanaman

Ulangi sampai tanaman selesai disiram.

Loop tetap perlu aturan: berapa kali diulang, selamanya, atau sampai kondisi tertentu terpenuhi.
SCRATCH CONTROL BLOCKS

Di Scratch Ada 3 Jenis Loop yang Sering Dipakai

Masing-masing punya fungsi berbeda. Pilih sesuai kebutuhan program.

repeat 10

Repeat [n]

Dipakai kalau jumlah pengulangannya sudah jelas. Contoh: lompat 3 kali.

forever

Forever

Dipakai kalau aksi berjalan terus selama project aktif. Contoh: awan bergerak terus.

repeat until <kondisi>

Repeat Until

Dipakai sampai kondisi tertentu terjadi. Contoh: ulangi sampai menyentuh garis finish.

Kenapa Costume Penting?

Animasi di Scratch sering dibuat dengan cara mengganti costume secara cepat. Semakin rapi urutan costume-nya, semakin halus gerakannya.

Kalau sprite hanya punya satu costume, block next costume tidak akan terlihat berubah.
