Langkah 1: Menambahkan Variabel Skor 📦🔢

1. Buat Variable "Score"

Klik menu Variables ➜ Klik Make a Variable ➜ Beri nama Score (For all sprites).

when green flag clicked
set Score to 0

2. Tambah Skor Saat Balon Meletus

Di dalam blok deteksi gerakan video:

if video motion on sprite > 20 then
  change Score by 1
  hide
  wait 0.5 seconds
  go to random position
  show

Langkah 2: Menambahkan Efek Suara "Pop" 🎵🎈

🔊 💥 🎈
Efek suara membuat game terasa lebih hidup!

Pasang Blok Sound

Tepat sebelum balon sembunyi (hide), masukkan blok suara start sound Pop.

start sound (Pop v)
change Score by 1
hide
Gunakan start sound (bukan play sound until done) agar gerakan balon tidak tersendat!

Langkah 3: Menambahkan Timer Countdown (30 Detik) ⏱️

Di Backdrop / Stage:

Buat variabel Timer. Atur waktu awal ke 30 detik, lalu kurangi 1 setiap detik.

when green flag clicked
set Timer to 30
repeat until <(Timer) = 0>
  wait 1 seconds
  change Timer by -1
broadcast (Game Over v)

Tantangan 30 Detik!

Pemain harus melambaikan tangan dan meletuskan balon sebanyak-banyaknya sebelum Timer mencapai angka 0.

Berapa skor tertinggi yang bisa kamu dan temanmu capai?

Langkah 4: Layar Game Over & Stop All 🛑

🏆 🏁 🛑

Game Selesai!

Merespons Pesan "Game Over"

Saat pesan Game Over diterima: sembunyikan balon, tampilkan pesan skor akhir, dan hentikan permainan.

when I receive (Game Over v)
hide
say (join [Permainan Selesai! Skormu: ] (Score)) for 3 seconds
stop (all v)

Eksperimen: Uji Sensitivitas Gerakan 📊

🍃

Threshold = 10 (Sensitif)

Gerakan kecil saja sudah membuat balon meletus. Cocok jika lampu ruangan agak redup.

⚖️

Threshold = 20 (Ideal)

Memerlukan lambaian tangan yang jelas dan terarah. Sangat pas untuk gameplay seimbang.

🌪️

Threshold = 40 (Tinggi)

Membutuhkan ayunan tangan cepat dan kuat. Game terasa lebih menantang!

Kamu bisa mencoba mengubah angka threshold di komputermu sendiri untuk menemukan settingan paling seru!

Testing: Cek Game Lengkapmu 🧪

Klik checklist di bawah setelah mencoba game di Scratch.

Skor di-reset menjadi 0 saat klik bendera hijau.
Skor bertambah +1 setiap kali balon terkena lambaian tangan.
Suara "Pop" berbunyi nyaring saat balon meletus.
Timer berjalan mundur dari 30 hingga 0.
Game berhenti otomatis dan menampilkan skor akhir saat waktu habis.
Semua fitur bekerja mulus tanpa bug!
