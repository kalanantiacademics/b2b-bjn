Face Sensing: Titik di Wajah 🟡

Peta Koordinat Wajah

Bayangkan wajah seperti peta. Program memasang titik kecil di area penting sehingga Scratch bisa mengecek status:

✅ Jika wajah ditemukan: Variabel status = "Yes" (Ada yang melihat).
❌ Jika wajah tidak terlihat: Variabel status = "No" (Aman, tidak ada yang melihat).
Privasi Aman: Kita tidak menyimpan foto siapa pun. Kamera hanya dipakai langsung untuk logika game!

Sprite Window = Otak Pengatur Kamera 🪟📷

🪟🤖

Kenapa Menggunakan Window?

Sprite Window terlihat seperti jendela kecil di panggung, tetapi perannya sangat vital: menjalankan pendeteksian wajah terus-menerus dan memperbarui variabel status.

turn video on: Menyalakan kamera di Scratch.
video transparency 0: Kamera terlihat jernih.
is someone looking: Variabel penyimpan Yes / No.
face detected?: Sensor pendeteksi wajah.

Kode di Sprite Window 🧱🪟

Alur Kode Window:

1. Awal: Nyalakan video, set transparansi ke 0, dan set variabel is someone looking = No.
2. Forever Loop: Cek terus apakah ada wajah (if face detected?).
3. Jika ada: Set is someone looking = Yes.
4. Jika tidak ada: Set is someone looking = No.
