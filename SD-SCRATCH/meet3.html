CORE CONCEPT

Sprite dan Backdrop Itu Apa?

Dua bagian ini membuat project terlihat seperti cerita atau game.

🎭

Sprite

Karakter atau objek yang bisa diberi program. Contoh: girl, hen, rooster.

🌄

Backdrop

Latar belakang tempat Sprite berada. Contoh: kebun, padang rumput, atau farm.

Sprite bisa bergerak dan berbicara. Backdrop membuat suasana project menjadi jelas.

🛠️ Cara Remix

1. Buka link starter project.
2. Klik tombol Remix di kanan atas.
3. Project akan tersalin ke akunmu.
4. Setelah itu, kamu bisa mengedit Sprite dan block-nya.

CODE 1

Program untuk Girl Character

Sprite karakter utama cukup menyapa saat green flag diklik.

👧💬Tugasnya

Ketika bendera hijau diklik, karakter akan mengucapkan kalimat pembuka. Gunakan block when green flag clicked dan say.

🟢 when green flag clicked
say “Welcome to my garden!” for 2 seconds
CODE 2

Program untuk Hen

Hen akan terlihat bergerak karena costume-nya berubah bergantian.

🐔🎭

Animasi Costume

Gunakan next costume dan wait agar gerakan tidak terlalu cepat.

Kamu boleh mengganti angka wait jika animasi terlihat terlalu cepat atau terlalu lambat.
CODE 3

Program untuk Rooster

Rooster juga memakai next costume agar terlihat hidup.

🐓⏱️Jangan Lupa Wait

Kalau costume berubah tanpa jeda, animasinya bisa terlalu cepat. Block wait membantu mata kita melihat perubahan costume.

Urutan umum: green flag → next costume → wait → next costume → wait.
