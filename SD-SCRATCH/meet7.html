REMIX RESPONSIBLY

Apa Itu Remix?

Remix artinya membuat salinan project orang lain supaya bisa kamu ubah dan kembangkan.

Remix bukan berarti menghapus nama pembuat asli. Scratch membantu kita tetap memberi credit.

Saat project di-remix, Scratch menampilkan keterangan bahwa project baru berasal dari project asli.

Artinya: meskipun kita mengubah banyak hal, pembuat awal tetap dihargai.

STEP: UPLOAD SPRITE

Menggunakan Gambar dari Internet sebagai Sprite

Teacher akan menunjukkan cara mencari gambar, menyimpan di device, lalu upload ke Scratch.

Checklist Sebelum Upload

1. Cari gambar yang aman dan sesuai project.
2. Simpan file di folder yang mudah ditemukan.
3. Klik Choose a Sprite → Upload Sprite.
4. Catat sumber gambar untuk bagian Credits.
STEP: UPLOAD BACKDROP

Menggunakan Backdrop dari Luar Scratch

Backdrop membuat suasana project jadi lebih menarik.

Ingat: Pilih yang Aman

Jangan upload foto rumah, foto sekolah, atau gambar yang berisi informasi pribadi.

Gunakan backdrop umum seperti taman, langit, hutan, kota kartun, atau gambar yang kamu buat sendiri.
PAINT EDITOR

Menggambar Sprite Sendiri

Paint Editor di Scratch mirip seperti aplikasi menggambar sederhana. Kamu bisa membuat karakter original.

Karakter original = kamu pembuatnya. Kamu tetap boleh menulis “Sprite by me” di Credits.
DRAW YOUR WORLD

Menggambar Backdrop Sendiri

Kamu bisa membuat latar taman, rumah, pulau, luar angkasa, atau dunia imajinasimu sendiri.

Backdrop buatan sendiri membuat project terasa lebih unik dan aman dari masalah hak cipta.

NEW CONCEPT

Clone = Salinan Sementara dari Sprite

Clone itu seperti bayangan atau duplikat sementara dari sprite. Sprite utama tetap ada, tetapi clone bisa punya aksi sendiri.

Di project ini: sheep utama diklik, lalu membuat clone kecil yang bergerak dan menghilang.
