LOOPING CONCEPT

Dua Program, Output yang Sama

Run kedua program dan bandingkan jumlah baris kodenya.

Tanpa Loop 
print("Hello World!")
print("Hello World!")
print("Hello World!")
print("Hello World!")
print("Hello World!")
Dengan Loop 
for i in range(5):
    print("Hello World!")
LOOPING CONCEPT 2

Loop Juga Bisa Menghasilkan Nilai Berbeda

Kedua program menampilkan angka 1 sampai 5.

Tanpa Loop 
print(1)
print(2)
print(3)
print(4)
print(5)
Dengan Loop 
for i in range(1, 6):
    print(i)
Looping menjalankan pola yang sama beberapa kali. Nilai i dapat berubah pada setiap pengulangan.
