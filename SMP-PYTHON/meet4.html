WHY OPERATORS?

Data Perlu Diolah

Input dan variabel baru menyimpan data. Operator membantu program menghitung, membandingkan, dan menghasilkan informasi baru.

Python tidak hanya menyimpan data.

Python bisa mengolah data menjadi hasil yang berguna.

➕

✖️

➗

REMEMBER DATA TYPES

Angka Tanpa Kutip Bisa Dihitung

Kalau angka ditulis sebagai string, Python akan memperlakukannya sebagai teks.

Run Syntax

print(10 + 5)
print("10 + 5")
print("10" + "5")
print(10 * 5)
Investigate: apakah Python menghitung, menampilkan teks, atau menggabungkan teks?

Output

Klik Run pada salah satu syntax.
IMPORTANT

Input dari User Masih Berupa String

Kalau ingin menghitung hasil input, kita perlu mengubahnya menjadi angka.

Gunakan int(input(...)) untuk bilangan bulat dan float(input(...)) untuk bilangan desimal.

Contoh

num1 = int(input("Enter number: "))
num2 = int(input("Enter number: "))
print(num1 + num2)

Tanpa int(), angka dari input belum siap dihitung.

DEBUG MINI ACTIVITY

Kenapa Hasilnya Jadi 1020?

Pilih versi kode yang benar agar input bisa dihitung sebagai angka.

⚠️

Versi A

a = input("A: ")
b = input("B: ")
print(a + b)
✅

Versi B

a = int(input("A: "))
b = int(input("B: "))
print(a + b)
Pilih kode yang menurutmu benar.
COMPARISON OPERATORS

Operator untuk Membandingkan

Selain menghitung, Python juga bisa membandingkan nilai dan menghasilkan True atau False.

10 > 5 → True
3 < 2 → False
8 == 8 → True
7 != 9 → True
5 >= 5 → True
4 <= 1 → False
Operator perbandingan sering dipakai nanti saat kita belajar conditional: if.

CODE STEP

Isi File learn-operator.py

Program

num1 = int(input("Enter the first number: "))

CODE STEP

Isi File count-garden.py

Ketik kode berikut untuk membuat kalkulator kebun.

Program

print("KALKULATOR KEBUN")
print("====================")

length = float(input("Panjang kebun (meter): "))
width = float(input("Lebar kebun (meter): "))

area = length * width

seeds = int(input("Jumlah bibit: "))
seeds_price = int(input("Harga satu bibit: Rp"))

total_price = seeds * seeds_price

water_per_meter = 2
water_needs = area * water_per_meter

print("HASIL PERHITUNGAN")
print("====================")
print("Luas kebun       :", area, "m²")
print("Total biaya bibit: Rp", total_price)
print("Kebutuhan air    :", water_needs, "liter")

Fokus Coding

📏

Panjang dan lebar bisa berupa angka desimal.

🔢

int()

CODE STEP

Isi File count-area.py

Kode ini lebih panjang, jadi ketik pelan-pelan dan cek setiap bagian.

Program

print("AREA CALCULATOR")
print("========================")

# Square
print("1. SQUARE")
side = float(input("Masukkan panjang sisi: "))
square_area = side * side
print("Square area =", square_area)

# Triangle
print("2. TRIANGLE")
base = float(input("Masukkan panjang alas: "))
height = float(input("Masukkan tinggi: "))
triangle_area = 0.5 * base * height
print("Triangle area =", triangle_area)

# Rectangle
print("3. RECTANGLE")
length = float(input("Masukkan panjang: "))
width = float(input("Masukkan lebar: "))
rectangle_area = length * width
print("Rectangle area =", rectangle_area)

# Circle
print("4. CIRCLE")
radius = float(input("Masukkan jari-jari: "))
circle_area = 3.14 * radius * radius
print("Circle area =", circle_area)

print("========================")
print("ALL CALCULATIONS COMPLETE")
