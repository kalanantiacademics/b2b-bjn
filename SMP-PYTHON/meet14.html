MAIN FORMULA

Rumus Utama Perhitungan

Total Air = (Luas Lahan × Base Water Rate × Faktor Musim) × Faktor Irigasi
Hasil akhir akan ditampilkan dalam Liters/day.
COMPONENTS

Apa Saja Komponen Rumusnya?

📏

Luas Lahan

Semakin luas area, semakin besar total air.

🌾

Crop Type

Vegetables 4.0, Corn 6.0, Rice 8.0 L/m²/day.

☀️

Season

Dry ×1.2, Rainy ×0.8.

💧

Drip Irrigation

Jika dicentang, total ×0.8.

CROP WATER RATE

Base Water Rate Berdasarkan Tanaman

🥬

Vegetables

4.0 L/m²/day
Sayuran daun relatif lebih sedikit karena akar dangkal dan masa tanam pendek.

🌽

Corn

6.0 L/m²/day
Jagung lebih besar dan butuh air untuk pembentukan tongkol.

🌾

Rice

8.0 L/m²/day
Padi membutuhkan air tinggi karena tumbuh di tanah basah/sawah.

Aliran Air di Lahan

Teknik irigasi memengaruhi efisiensi penggunaan air.

Season & Irrigation Factor

Dry season ×1.2: air lebih cepat menguap, jadi kebutuhan naik 20%.

Rainy season ×0.8: tanah mendapat bantuan air hujan, jadi kebutuhan turun 20%.

Drip irrigation ×0.8: air langsung ke akar, jadi lebih hemat.

MANUAL SIMULATION

Contoh Perhitungan Manual

Area 100 m², Corn, Dry Season, Drip Irrigation.

1

Base Water

100 m² × 6.0 L/m² = 600 Liters

2

Dry Season

600 Liters × 1.2 = 720 Liters

3

Drip Irrigation

720 Liters × 0.8 = 576.0 Liters/day

Import, Window, Variable, dan Function

import customtkinter as ctk

app = ctk.CTk()
app.title("Crop Water Calculator")
app.geometry("380x600")
app.resizable(False, False)

ctk.set_appearance_mode("light")
season_var = ctk.StringVar(value="Dry")

def calculate_water():
    area_text = entry_area.get()
    crop_type = combo_crop.get()
    season = season_var.get()
    is_drip = check_drip.get()

    try:
        area = float(area_text)
        if area <= 0:
            lbl_result.configure(text="⚠️ Area must be greater than 0!", text_color="#EF4444")
            return
    except ValueError:
        lbl_result.configure(text="⚠️ Enter a valid number for Area!", text_color="#EF4444")
        return

    base_water_rate = 5.0
    if crop_type == "Rice 🌾": base_water_rate = 8.0
    elif crop_type == "Corn 🌽": base_water_rate = 6.0
    elif crop_type == "Vegetables 🥬": base_water_rate = 4.0
FULL PROGRAM • PART 2

    season_multiplier = 1.2 if season == "Dry" else 0.8
    total_water = area * base_water_rate * season_multiplier
    if is_drip == 1:
        total_water *= 0.8

    lbl_result.configure(
        text_color="#1E293B",

             f"🌱 Crop: {crop_type}\n\n"
