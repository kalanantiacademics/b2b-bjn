PYTHON GUI LIBRARY

Apa Fungsi Tkinter?

Tkinter membantu kita membuat aplikasi visual seperti window, text box, button, menu, dan area tampilan. Jadi script Python yang tadinya hanya berjalan di terminal bisa punya tampilan yang lebih ramah.

CustomTkinter adalah versi modern yang membuat widget terlihat lebih rapi, rounded, dan mudah diatur warnanya.

VENV

Kenapa Kita Perlu Virtual Environment?

Bayangkan setiap project punya “kotak alat” sendiri. Library yang dipakai project ini disimpan di kotak itu, sehingga tidak mengganggu project lain.

Virtual environment membantu project Python lebih rapi dan aman saat kita mulai memakai library tambahan.

Tidak Berantakan

STEP 1

Buat Virtual Environment

Buka terminal di VS Code, lalu ketik command berikut.

Command

python -m venv .venv
Jika command python tidak dikenali, coba gunakan py -m venv .venv.
STEP 2

Cek Folder .venv

Setelah command berhasil, akan muncul folder baru bernama .venv.

STEP 3

Aktifkan Virtual Environment

Di terminal, jalankan command aktivasi.

Windows PowerShell

.venv\Scripts\Activate.ps1
Jika berhasil, biasanya terminal akan menampilkan tanda (.venv) di awal baris.
STEP 4

Install CustomTkinter

Setelah venv aktif, baru install library yang kita pakai.

Command

pip install customtkinter
Tunggu sampai proses selesai. Jangan menutup terminal saat install masih berjalan.
INSTALLATION CHECK

Tunggu Sampai Install Selesai

Kalau sudah selesai, kita bisa coba menjalankan program pertama.

FIRST WINDOW

Sekarang Tulis Program Pertama

File: learn-tkinter.py. Ini hanya membuat window kosong.

Code

import customtkinter as ctk

app = ctk.CTk()
app.title("Learn Tkinter First")
app.geometry("400x600")

app.mainloop()

Apa yang Harus Terjadi?

Ketika dijalankan, akan muncul window desktop baru berukuran 400 x 600 dengan title “Learn Tkinter First”.

Kalau window muncul, berarti setup Tkinter kamu berhasil.
READ THE CODE

IMPROVE THE WINDOW

Tambahkan Pengaturan Window

Sekarang kita membuat window lebih rapi: tidak bisa di-resize, mode light, dan tema biru.

import customtkinter as ctk

app = ctk.CTk()
app.title("Learn Tkinter First")
app.geometry("400x600")
app.resizable(False, False)
ctk.set_appearance_mode("light")
ctk.set_default_color_theme("blue")

app.mainloop()

Hasil Window

Window kosong yang siap diisi widget.

NEW LINES

Baris Tambahan Ini Untuk Apa?

📏

app.resizable(False, False)

Membuat window tidak bisa dibesarkan atau dikecilkan. Ukurannya tetap.

☀️

set_appearance_mode("light")

Mengatur tampilan aplikasi menjadi light mode.

🔵

set_default_color_theme("blue")

Mengatur warna tema default menjadi biru.

Mulai hari ini kita tidak hanya memikirkan logic, tapi juga tampilan aplikasi.
