BIG IDEA

Kenapa Kita Perlu Looping?

Looping membantu program jadi lebih singkat, lebih rapi, dan mengurangi penulisan berulang yang tidak perlu.

Tanpa Loop

print("Hello World")
print("Hello World")
print("Hello World")
print("Hello World")
print("Hello World")
print("Hello World")
print("Hello World")
print("Hello World")
print("Hello World")
print("Hello World")
Barisnya panjang, membosankan, dan gampang salah saat mengetik ulang.

Pakai Loop

for i in range(10):
    print("Hello World")
Hasil output sama, tapi kodenya jauh lebih singkat dan efisien.

Kalau hasilnya sama, kamu pilih yang mana?

Kebanyakan programmer akan memilih kode yang lebih singkat, jelas, dan mudah dirawat. Nah, itulah alasan kita belajar looping.

WHILE LOOP

Mulai dari while True:

while berarti “selama kondisi masih benar, jalankan blok kode lagi”.

Contoh paling sederhana

while True:
    print("this is an infinite loop, stop the program to stop me")

Karena kondisinya selalu True, program akan berjalan terus menerus.

♾️

Infinite Loop

Loop seperti ini disebut infinite loop karena tidak punya akhir otomatis.

Kalau program berjalan terus, kita bisa menghentikannya dengan tombol Ctrl + C di terminal atau tombol stop.

FOR LOOP

Jenis Loop Lain: for

Kalau jumlah pengulangannya sudah kita ketahui, biasanya for lebih cocok digunakan.

Kapan pakai while?

Saat kita belum tahu pasti harus mengulang berapa kali.

Contoh: ulangi sampai user mengetik exit.

Kapan pakai for?

Saat jumlah pengulangannya sudah diketahui.

Contoh: cetak teks 5 kali, hitung 0 sampai 10, atau proses 3 data.

Singkatnya

while cocok untuk “selama kondisi masih benar”, sedangkan for cocok untuk “ulangi sebanyak N kali”.
