VARIABLE

Pernah Dengar Variabel?

Bayangkan variabel sebagai kotak dengan label yang digunakan untuk menyimpan value.

Contoh Kotak

name  → Adrian
age   → 13
hobby → Sports

Label membantu program tahu data mana yang sedang dipakai.

VARIABLE USE

Variabel Menyimpan Nilai untuk Dipakai Lagi

Setelah data disimpan dan diberi label, program bisa memanggilnya kembali untuk proses lain.

📥

Menerima Data

Program menerima value dari user atau dari kode.

🏷️

Memberi Label

Value disimpan dalam nama variabel.

💾

Menyimpan

Data tidak langsung hilang setelah user mengetik.

📤

Memakai Lagi

Variabel dapat dipanggil untuk print atau proses lain.

DATA TYPES

Empat Tipe Data Dasar

Tipe data membantu komputer memahami perlakuan yang tepat untuk sebuah value.

📝

String

Teks atau karakter. Biasanya memakai tanda kutip.

"Lily"
🔢

Integer

Bilangan bulat, bisa dipakai untuk operasi matematika.

21
📏

Float

Bilangan desimal, misalnya tinggi atau berat.

12.5
✅

Boolean

Nilai benar atau salah.

True / False
WHY IT MATTERS

Kenapa Kita Harus Belajar Data Types?

Karena komputer perlu tahu apakah data harus dihitung sebagai angka atau diperlakukan sebagai teks.

Kalau kita menulis print(21 + 11), Python tahu itu operasi matematika. Kalau kita menulis print("21" + "11"), Python melihatnya sebagai teks.
🧮 vs 📝
print(21 + 11)   # 32
print("21"+"11") # 2111

Angka bisa dihitung. String digabung sebagai teks.

PRACTICE 3

Buat File Baru: learn-datatypes.py

Kita akan meminta input dan mengelompokkan data ke tipe yang berbeda.

Program

# String
flower = input("Masukkan nama bunga: ")
description = input("Deskripsikan bunga tersebut: ")

# Integer
petals = int(input("Masukkan jumlah kelopak bunga: "))

# Float
height = float(input("Masukkan tinggi bunga dalam cm: "))

# Boolean
fragrant = input("Apakah bunga memiliki aroma? (True/False): ")

print("FLOWER INFORMATION")
print("=====================")
print("Nama bunga      :", flower)
print("Deskripsi       :", description)
print("Jumlah kelopak  :", petals)
print("Tinggi bunga    :", height, "cm")
print("Memiliki aroma  :", fragrant)
