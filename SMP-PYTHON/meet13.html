NEW WIDGET

Entry = Kotak untuk Mengetik Input

Entry digunakan saat aplikasi perlu meminta data dari user, misalnya nama, email, nama tanaman, jumlah, harga, luas area, atau kebutuhan perawatan.

Entry biasanya disimpan ke variabel, karena nanti isi yang diketik user perlu diambil lagi dengan .get().
ENTRY ANATOMY

Cara Membuat Entry di CustomTkinter

entry_name = ctk.CTkEntry(
    app,
    placeholder_text="Type your name...",
    font=("Segoe UI Rounded", 14),
    width=200,
    height=40,
    corner_radius=10,
    justify="center"
)
entry_name.pack(pady=10)
Welcome App
Type your name...
READ THE PROPERTIES

Bagian Entry yang Bisa Diatur

placeholder_text

Teks bantuan yang muncul sebelum user mengetik.

font

Mengatur jenis dan ukuran tulisan di textbox.

width / height

Mengatur ukuran Entry.

corner_radius

Mengatur rounded corner pada kotak input.

justify

Mengatur posisi teks: left, center, atau right.

entry_name = ...

Entry disimpan di variabel agar bisa dibaca kembali.

TRY IT

Kalau Butuh Dua Input, Duplicate Entry

Ganti nama variabel agar setiap textbox punya tempat data sendiri.

Bagaimana Mengambil Data dari Entry?

                
Isi yang diketik user tidak otomatis muncul di Label. Kita perlu mengambilnya dengan .get().

User Type

➜

                
📥
                    
.get()

                    
entry_name.get() membaca isi textbox.

                

                
➜

                
🏷️
                    
configure()

                    
Label diubah untuk menampilkan hasil.

                

            

        


        

            

                
def submit_name():
    user_name = entry_name.get()

    if user_name.strip() != "":
        lbl_welcome.configure(
            text=f"Welcome, {user_name}! 👋"
        )
        lbl_message.configure(
            text="Have a nice day! ✨"
        )
    else:
        lbl_welcome.configure(
            text="Please enter your name!"
        )
        lbl_message.configure(text="")

                

                    
Kenapa Ada Conditional?

                    
if user_name.strip() != "" mengecek apakah input benar-benar
                        diisi. Ini mencegah aplikasi menampilkan welcome message kosong.

                    
Kalau user belum mengetik nama, program memberi pesan: Please enter your name!

FUNCTIONAL RADIO
                
Agar RadioButton Hanya Bisa Pilih Satu

            

            

                
radio_var = ctk.StringVar(value="Indoor")

radio1 = ctk.CTkRadioButton(
    frame_radio,
    text="Indoor",
    value="Indoor",
    variable=radio_var,
    ...
)

radio2 = ctk.CTkRadioButton(
    frame_radio,
    text="Outdoor",
    value="Outdoor",
    variable=radio_var,
    ...
)

                

                    
Kenapa Harus Pakai Variable yang Sama?

                    
radio_var menjadi tempat penyimpanan pilihan. Karena radio1 dan
                        radio2 memakai variable yang sama, pilihan aktif hanya satu.

                    
Nantinya pilihan dibaca dengan radio_var.get().
                    

                

            

        


        

            
FUNCTION
                
Buat Function untuk Menyimpan Data ke Preview

            

            

                
def submit_data():
    name = entry_name.get()
    category = combo_category.get()
    area_type = radio_var.get()
    needs_watering = "Yes" if check_water.get() == 1 else "No"

    if name.strip() != "":
        lbl_result.configure(
            text=f"🌱 Name: {name}\n\n"
                 f"📦 Category: {category}\n\n"
                 f"🏡 Area Type: {area_type}\n\n"
                 f"💧 Daily Watering: {needs_watering}"
        )
    else:
        lbl_result.configure(text="⚠️ Please enter a plant name first!")

                

                    
Kenapa Dicek dengan if?

                    
Minimal nama tanaman harus diisi agar data preview tidak kosong. Conditional membantu mengurangi
                        error input dan memberi feedback yang jelas ke user.

                

            

        


        

            

                
btn_submit = ctk.CTkButton(
    left_frame,
    text="Save Data ✨",
    font=("Segoe UI Rounded", 13, "bold"),
    height=38,
    corner_radius=8,
    fg_color="#22C55E",
    text_color="#FFFFFF",
    hover_color="#16A34A",
    command=submit_data
)
btn_submit.pack(fill="x", pady=(10, 0))

                

                    
Command Mengaktifkan Button

                    
Tanpa command=submit_data, button hanya terlihat tetapi belum
                        menjalankan proses apa pun.

                    
Saat button diklik: ambil semua value → validasi nama → tampilkan data di
                        lbl_result.
