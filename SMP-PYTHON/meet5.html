VERY IMPORTANT

Python Membaca Indentation

Di Python, spasi masuk ke dalam bukan hiasan. Indentation menentukan baris mana yang termasuk ke dalam if, elif, atau else.

Tab / 4 spasi ke dalam

Baris yang menjorok ke kanan berarti berada di dalam blok.

Aturan Dasar

if kondisi:
    print("baris ini masuk ke if")
    print("ini juga masuk ke if")
print("ini di luar if")
Tanda : seperti pintu. Setelah pintu terbuka, baris di dalamnya harus diberi indentation.
READING CODE

Mana yang Masuk ke Dalam If?

Klik setiap baris kode untuk melihat apakah baris itu berada di dalam blok if atau di luar.

if height >= 20:
print("Siap panen")
else:
print("Belum siap")
print("Tunggu lagi")
👀

Indent = Area Kerja

Klik salah satu baris kode.

Kalau indentation salah, Python bisa bingung dan menampilkan IndentationError.
