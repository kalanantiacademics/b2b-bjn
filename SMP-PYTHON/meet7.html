FUNCTION IDEA

Satu Nama, Banyak Instruksi

Function adalah sekumpulan code yang diberi nama agar bisa dipanggil kapan saja. Ini membuat program lebih rapi dan tidak perlu menulis ulang code yang sama.

Bayangkan function sebagai buku resep. Nama function = nama resep. Isi function = langkah-langkah memasak.

CALL FUNCTION

Function Harus Dipanggil

Kalau resep sudah ditulis, kita perlu memanggil nama resepnya untuk menjalankan langkah-langkahnya.

Cara Memanggil

Tulis nama function lalu tambahkan tanda kurung ().

Coba Klik Simulasi Ini

OUTPUT akan muncul di sini setelah function dipanggil.
Di Python, function tidak berjalan hanya karena sudah dibuat. Function berjalan saat dipanggil.
IMPORTANT

Indentation Menentukan Isi Function

Baris yang menjorok ke dalam adalah bagian dari function. Baris yang rata kiri berarti di luar function.

✅ Benar

def pancakes():
print("Ingredients...")
print("1. Whisk...")
print("2. Cook...")
Semua print masuk ke dalam function.

Contoh Salah

Line 3 dan 4 bukan bagian dari function karena tidak masuk indent.

List itu seperti Kotak Penyimpanan

Variabel biasanya menyimpan satu data. List bisa menyimpan beberapa data sekaligus.

LIST IDEA

Satu Nama, Banyak Isi

Contoh: colors = ["merah", "hijau", "kuning", "biru"]. Semua warna disimpan di satu list bernama colors.

List bisa ditambah dengan append, dikurangi dengan remove atau pop, dan isinya bisa diakses memakai index.
LIST INDEX

Nomor Index Selalu Mulai dari 0

Python menghitung posisi item list dari kiri ke kanan, dimulai dari angka 0.

index 0merah
index 1hijau
index 2kuning
index 3biru
Kalau kita menulis print(colors[1]), Python akan menampilkan item index 1, yaitu hijau.
INTERACTIVE ACTIVITY

Coba Manipulasi Isi List

Klik perintah di kanan dan lihat bagaimana isi list berubah.

Perintah List

Setiap item punya index. Kalau isi list berubah, nomor index juga ikut bergeser.
