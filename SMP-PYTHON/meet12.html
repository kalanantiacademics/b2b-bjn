STEP 4
                
Buat Function untuk Menambah Score

                
Function diletakkan sebelum button memanggilnya.

            

            

                
count = 0

def count_click():
    global count
    count = count + 1
    lbl_score.configure(text=str(count))

                

                    
Apa yang Terjadi?

                    
count dimulai dari 0. Setiap button diklik, function membaca
                        count, menambahnya 1, lalu mengubah text pada lbl_score.

                    
str(count) dipakai karena Label menampilkan text,
                        bukan angka murni.

NAVIGATION FUNCTION
                
Buat Function untuk Berpindah Frame

            

            

                
def show_frame(target_frame):
    frame_home.pack_forget()
    frame_farmers.pack_forget()
    frame_crops.pack_forget()
    frame_water.pack_forget()

    target_frame.pack(fill="both", expand=True)

                

                    
Apa Fungsi pack_forget()?

                    
pack_forget() menyembunyikan frame dari window. Setelah semua
                        frame disembunyikan, kita tampilkan frame yang dipilih dengan target_frame.pack(...).

                    
Cara berpikirnya: sembunyikan semua halaman → tampilkan halaman tujuan.

                

            

        


        

            
COMMAND DETAIL
                
Hubungkan Button Farmers ke Frame Farmers

            

            

                
btn_farmers = ctk.CTkButton(
    frame_grid,
    image=img_farmer,
    text="Farmers",
    compound="top",
    ...,
    command=lambda: show_frame(frame_farmers)
)

                

                    
Kenapa Pakai lambda?

                    
Karena kita ingin memanggil function dengan parameter: show_frame(frame_farmers). lambda
                        membuat perintah itu menunggu sampai button benar-benar diklik.

                    
Tanpa lambda, function bisa terpanggil terlalu cepat saat program baru dibuat.

Maksud Command Ini

                    
Ketika button Back diklik, program menjalankan show_frame(frame_home). Semua frame disembunyikan, lalu home
                        ditampilkan kembali.
