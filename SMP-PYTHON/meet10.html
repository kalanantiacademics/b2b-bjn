STARTER CODE

Setiap Project Tkinter Dimulai dari Struktur Ini

Bagian tengah adalah tempat kita menaruh widget.

import customtkinter as ctk

app = ctk.CTk()
app.title("Plant Dictionary")
app.geometry("350x450")

ctk.set_appearance_mode("light")

# disini tempat kita naro widget-widgetnya

app.mainloop()

Yang Harus Diingat

app adalah window utama. Semua widget yang ingin muncul di window ini harus ditempatkan ke dalam app.

Tanpa app.mainloop(), window bisa langsung tertutup.
🏷️
TKINTER WIDGET

Label = Teks yang Ditampilkan di Window

Di CustomTkinter, kita memakai ctk.CTkLabel() untuk membuat text seperti judul, instruksi, caption, status, atau icon emoji.

Label tidak muncul otomatis. Setelah dibuat, widget harus ditampilkan dengan layout command seperti .pack().
ctk.CTkLabel(
    app, # posisi label ini dimana
    text="Plant Dictionary", # text yang ditampilkan
    font=("Arial", 26, "bold"), # font style dan size
    text_color="#1B5E20" # font color
)

Kenapa Ada ctk.?

CTkLabel adalah class bagian dari CustomTkinter. Karena kita import sebagai ctk, maka cara panggilnya adalah ctk.CTkLabel(...).

Label ini sudah dibuat, tapi belum tampil kalau belum diberikan .pack().
SHOW THE WIDGET

Supaya Muncul, Tambahkan .pack()

ctk.CTkLabel(
    app,
    text="Plant Dictionary",
    font=("Arial", 26, "bold"),
    text_color="#1B5E20"
).pack()

LAYOUT

Mengenal .pack(side=...)

side menentukan widget menempel di sisi mana.

⬆️

side="top"

Widget muncul dari atas ke bawah. Ini default pack.

⬇️

side="bottom"

Widget ditempatkan di bagian bawah window.

↔️

side="left" / "right"

Widget ditempatkan dari sisi kiri atau kanan.

Contoh: .pack(side="bottom", pady=30) membuat label “Loading app...” berada di bawah.
PADDING

Bedanya padx dan pady

Padding adalah jarak kosong di sekitar widget.

padx = jarak kiri-kanan

Label

Contoh: .pack(padx=25)

pady = jarak atas-bawah

Label

Contoh: .pack(pady=(5,25))

EXAMPLES

Format Pack yang Sering Dipakai

.pack()

Menampilkan widget dengan posisi default.

.pack(side="bottom")

Menaruh widget di bagian bawah.

.pack(pady=25)

Memberi jarak atas-bawah sebesar 25 pixel.

.pack(padx=25)

Memberi jarak kiri-kanan sebesar 25 pixel.

.pack(pady=(5, 25))

Jarak atas 5 pixel, bawah 25 pixel.

.pack(padx=(5, 25))

Jarak kiri 5 pixel, kanan 25 pixel.

Kenapa Import PIL?

                    
PIL berasal dari package Pillow. Package ini membantu
                        Python membuka file gambar seperti JPG atau PNG agar bisa dipakai di Tkinter.

                    
Kalau belum install Pillow, bagian from PIL import
                            Image bisa error.

IMAGE WIDGET
                
Buat Variabel title_image

                
Variabel ini menyimpan widget image yang nanti dipasang ke Label.

            

            

                

                    
Program

                    
Open image lalu buat CTkImage.

                

                
image_path = Image.open("plant.jpg")

title_image = ctk.CTkImage(
    light_image=image_path,
    dark_image=image_path,
    size=(200, 200)
)

            

        


        

            
IMPORTANT
                
Image Tetap Ditampilkan Lewat Label

                
CTkImage adalah object image. Agar terlihat di window, image dipasang pada ctk.CTkLabel().

            

            

                
ctk.CTkLabel(
    app,
    image=title_image,
    text=""
).pack(pady=10)

                

                    
Kenapa text=""?

                    
Karena Label ini dipakai untuk menampilkan gambar, bukan teks. Jadi teksnya dikosongkan, lalu
                        image diambil dari variabel title_image.

                    
Rumus mudah: Image file → CTkImage variable → CTkLabel(image=...)

Full Code tkinter-image.py

            

            
import customtkinter as ctk
from PIL import Image

app = ctk.CTk()
app.title("Image Viewer")
app.geometry("350x450")

ctk.set_appearance_mode("light")

image_path = Image.open("plant.jpg")

title_image = ctk.CTkImage(
    light_image=image_path,
    dark_image=image_path,
    size=(200, 200)
)

ctk.CTkLabel(
    app,
    text="Plant Dictionary",
    font=("Arial", 24, "bold"),
    text_color="#1B5E20"
).pack(pady=(30, 15))

ctk.CTkLabel(
    app,
    image=title_image,
    text=""
).pack(pady=10)

ctk.CTkLabel(
    app,
    text="Complete Guide & Flora Directory",
    font=("Arial", 14, "italic"),
    text_color="#555555"
).pack(pady=10)

app.mainloop()
